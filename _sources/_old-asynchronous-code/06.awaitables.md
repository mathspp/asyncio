# Awaitables

When you hit the keyword `await`, the **event loop** gets the chance to work on something else.
That's why it's said that `asyncio` allows you to run **cooperative concurrency**:
because switching to a different task only happens when _you_ allow it.
And you allow it by using the keyword `await`.

But the keyword `await` can't be used in arbitrary locations.
First, it can only be used inside **asynchronous functions**, which are functions marked with the keyword `async`:

```py
async def f():
    ...
```

The function `f`, shown above, is an asynchronous function because it's defined with `async def`, instead of just `def`.

The keyword `await` can also _only_ be used in front of **awaitables**.
**Awaitables** are special objects that the event loop knows to work with.
This means you can't use the keyword `await` in front of the functions `cook` and `microwave`, from earlier, to simulate an asynchronous preparation of your lunch.
In other words, this code will _not_ work:

```py
from kitchenkit import *
from kitchenkit.prep import cook, microwave

async def main():
    put_on_apron()
    meatloaf = await microwave(Meatloaf())
    pasta = await cook(Pasta())
    serve_food(pasta, meatloaf)

if __name__ == "__main__":
    main()
```

To be able to use a package asynchronously, the package must explicitly support asynchronous code execution.
Often, packages that support it will provide two different APIs:
one API works synchronously and the other API works asynchronously.
That's also the case with `kitchenkit`.

The package `kitchenkit` provides an asynchronous version of `cook` called `async_cook` and an asynchronous version of `microwave` called `async_microwave`.
Thus, you must replace `microwave` and `cook` with their respective async versions:

```py
from kitchenkit import *
from kitchenkit.prep import async_cook, async_microwave

async def main():
    put_on_apron()
    meatloaf = await async_microwave(Meatloaf())
    pasta = await async_cook(Pasta())
    serve_food(pasta, meatloaf)

if __name__ == "__main__":
    main()
```
