# Starting the event loop

Your function `main` is an _asynchronous function_, which you can tell by the keyword `async` in front of the function definition.
If you call the function `main`, the function doesn't _run_ like you're used to.
Since it's an _asynchronous function_, calling the function returns a **coroutine object**.

You can see this in the REPL with a simpler asynchronous function:

```pycon
>>> async def f():
...     print("Hello, world!")
...
>>> f()
<coroutine object f at 0x10ac1d9c0>
```

A **coroutine object** is an object that represents a task, but it doesn't start automatically.
You can verify that it didn't start automatically because the message `"Hello, world!"` wasn't printed to the screen.
