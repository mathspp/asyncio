# Chat application

In this section you'll develop your first asynchronous application: a Human-to-Human chat application that supports having multiple clients (Humans) connected in the same chatroom, exchanging messages between each other.

Your chat application will have a basic interface so you can focus on the asynchronous mechanisms that power your chat application.

## Learning objectives

In this section you'll learn to:

 - use `asyncio` for inter-process communication
 - use stream readers and writers to send data from a program to another
 - establish a protocol used by communicating programs
