# What's asynchronous code?

This course will teach you how to write, read, and run **asynchronous code**, but that requires you to understand what **asynchronous code** means.

That's what you'll learn in this section of the course.

## Learning objectives

The learning objectives for this section are:

 - understanding the differences between synchronous and asynchronous code
 - being able to identify tasks that could benefit from asynchronous code execution
