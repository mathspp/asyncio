# Exercises

In this section you're going to solve a couple of coding exercises.
For each exercise, you'll be asked to prepare a lunch with different combinations of ingredients.
Write a full, working program for each exercise and test it by running it.

## Exercise 1

Delete the file `async_lunch.py` and recreate it from scratch.
That is, prepare a lunch with
 - meatloaf that you must microwave
 - pasta that you must cook

When you're done, the code should run and lunch should be ready in 10.

## Exercise 2

Prepare a lunch with the following ingredients:
 - roasted chicken (`RoastedChicken`) that you must microwave
 - pasta that you must cook

When you're done, the code should run and lunch should be ready in 10.

## Exercise 3

Prepare a lunch with the following ingredients:
 - turkey (`Turkey`) that you must microwave
 - rice (`Rice`) that you must cook
 - couscous (`Couscous`) that you must cook

When you're done, the code should run and lunch should be ready in 10.
