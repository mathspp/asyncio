# Prerequisites

For this course, you'll need:

 - **prior Python knowledge**: you must be comfortable with writing and using functions, classes, and control flow like conditional statements and loops
 - **Python 3.12+**: code examples run on Python 3.12 or greater
 - **uv**: you'll use uv to manage and run your scripts and projects throughout the course

```{note}
Check [the uv documentation](https://docs.astral.sh/uv/) for the most up-to-date installation instructions.
```

You are also expected to work on the coding exercises yourself.
If you skip the exercises or use an LLM to complete them for you, you'll be hindering your own learning.
