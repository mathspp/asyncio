I/O-bound tasks

I/O-bound tasks#

Take the following piece of Python code and run it:

import urllib.request

_ = urllib.request.urlopen("https://httpbin.org/delay/3")
print("Done!")

This Python code uses the module urllib from the standard library to make a request to the page https://httpbin.org/delay/3 and then prints the message "Done!". How long does this snippet of code take to run?

If you run it, it’ll take roughly 3 seconds to finish. That’s because the HTTP request to the page specified in the argument to urlopen takes 3 seconds. You spent those 3 seconds waiting for the server to return the page you requested. During that time interval, your CPU was idle; it was doing nothing.

This network request is an example of an I/O-bound task: a task where most of the time spent is spent waiting for input or output. An I/O-bound task contrasts with a CPU-bound task, where the thing you’re waiting for is for your CPU to finish computing your results.

The snippet below shows an example of a CPU-bound task:

def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

print(fibonacci(40))

The function fibonacci is a recursive function that has some mathematical interest. For the purposes of this discussion, it’s enough to know that even with small arguments, the function gets really slow.

The task of computing the result of the function call fibonacci(40) is a CPU-bound task because the time you’re spending is your CPU doing function calls and performing calculations. On my computer, at the time of writing this, this snippet of code takes about 10 seconds to run. How long does it take for you?

Another tell that the fibonacci computation is a CPU-bound task is that the time it takes depends on the specs of your computer. If you have a really old computer, it’s going to take more than the 10 seconds it took me. If you have a modern and/or beefy computer, it’s going to take less than the 10 seconds it took me.

However, for I/O-bound tasks, the time it takes doesn’t depend on your own computer. Regardless of the machine you run it on, the first snippet of code in this page is going to take 3 seconds to run. Period.

What you’ll learn is that, while you can’t speed up I/O-bound tasks, you can use asynchronous code execution to speed up programs that need to run multiple I/O-bound tasks.
